# student_score_records
A simple student score records script written in Python

This program allows you to:

1. Add students records by:
    - student name
    - discipline
    - score

2. Search for a student in records and review last 'n' scores of the student by:
    - typing student name to search for in students records
    - type the number of last records you want to view for that student

3. See students records resume and promovation status

4. Save and load results from encrypted .pkl file
